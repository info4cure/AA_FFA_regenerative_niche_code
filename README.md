# Single-cell transcriptomic analysis of regenerative-niche remodeling in alopecia areata and frontal fibrosing alopecia

## Overview

This repository contains the analysis code and reproducibility resources associated with a single-cell RNA-sequencing study comparing scalp tissue from patients with alopecia areata (AA), frontal fibrosing alopecia (FFA), and healthy controls (HC).

The analysis investigates disease-specific remodeling of the hair-follicle regenerative niche and its surrounding epithelial, mesenchymal, vascular, and immune compartments.

The repository includes code for:

- single-cell RNA-seq preprocessing and quality control;
- integration and cell-type annotation;
- epithelial and non-epithelial subpopulation analysis;
- patient-level differential abundance;
- pseudobulk differential expression;
- pathway and gene-set enrichment analysis;
- Bulge/Isthmus regenerative-niche characterization;
- trajectory and functional-state analyses;
- epithelial, mesenchymal, vascular, and immune ecosystem analyses;
- ligand-receptor and multicompartment cell-cell communication analysis;
- transcription-factor/regulatory analyses;
- Geneformer-based in silico perturbation analyses;
- generation of publication figures.

This repository contains analysis code and metadata required to reconstruct the analytical workflow. Large primary sequencing files and other deposited datasets are not duplicated in the repository and should be obtained from the corresponding public data repositories.

Data availability

The repository does not contain raw sequencing data or large intermediate analysis objects.

Publicly available datasets and accession identifiers used in the study are documented in:

* metadata/GEO_accession_mapping.tsv
* metadata/sample_manifest.csv

Users should obtain the corresponding sequencing data from the public repositories indicated in these files.

Reproducibility

The reproducibility/ directory contains records describing the provenance and execution of the analytical workflow:

* METHODS_PROVENANCE.tsv — provenance of major analytical steps;
* scrnaseq_provenance_manifest.tsv — sanitized sample-level provenance information;
* code_manifest.tsv — manifest of analysis code;
* execution_manifest.tsv — execution records for the analytical workflow.

Local filesystem paths and machine-specific identifiers have been removed from the public release.

Software environment

The R package versions used for the single-cell analyses are recorded in:

environment/scrnaseq_R_package_versions_20260924.txt

Additional analysis configuration is provided in:

config/analysis_config.yaml

Figure palettes and graphical conventions are defined in:

config/figure_palette_v2.R

Running the analysis

The analysis is organized as a modular workflow. The main pipeline scripts are located under:

code/pipeline/

Specialized downstream analyses are located under:

code/advanced/

Geneformer-based analyses are located under:

code/geneformer/

Scripts used to generate final publication figures are located under:

code/figures/

A project-level launcher is provided as:

code/run_joint_paper_pipeline.sh

Individual scripts may require outputs generated by preceding analytical stages and access to the corresponding deposited datasets. The manifests in reproducibility/ document the relationship between analytical steps and generated outputs.

Geneformer analyses

Geneformer-based in silico perturbation analyses are provided separately under code/geneformer/.

The repository contains the analysis scripts required for these experiments but does not redistribute pretrained Geneformer model weights. Users should obtain compatible Geneformer models from their original distribution source and configure the local model path before executing these analyses.

Publication figures

Final scripts used to generate the principal downstream publication figures are provided in code/figures/.

These scripts correspond to the finalized analytical outputs used for manuscript figure generation. Intermediate and historical figure-development scripts are not required for reproducing the final figures.

Notes

This release is intended to provide a transparent record of the computational analyses supporting the associated manuscript. Because several stages depend on large intermediate single-cell objects and externally distributed resources, reproducing the complete workflow from raw sequencing data requires downloading the corresponding deposited data and installing the software dependencies described above.
